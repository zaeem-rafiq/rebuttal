# Critique: console (Next.js 14 Risk Operations Console for Rebuttal)

- **Target**: console
- **Score**: 35/40 (Good — Upper Tier)
- **Priority Issues**: 0 P0, 0 P1, 2 P2, 3 P3

## 1. Design Specificity Verdict
High-conviction, disciplined institutional risk defense console. Stripped of AI SaaS gradient clichés and evaluative meta-signage in favor of dark slate tonal layering, crisp borders, and monospaced financial data. Concession safeguard eliminates accidental fund forfeiture, and win rate calculation correctly evaluates only resolved disputes.

## 2. Priority Issues
- [P2] Zero-case win rate display: When no disputes have been resolved yet (empty DB or brand-new merchant), fallback shows 100% instead of an em-dash (`—%`) or 'No resolved cases'.
- [P2] Case Details header prop synchronization: Header on `/case/[id]` does not pass `onRefresh` or `isRefreshing`, hiding the manual refresh button visible on the index dashboard.
- [P3] Minor contrast on micro-labels: `.text-[10px].text-slate-500` on metric card subtitles is close to the 4.5:1 boundary on dark canvas; consider `text-slate-400`.
- [P3] Interactive phone container: Sticky sidebar container on large desktop could benefit from a subtle min-height lock to avoid slight layout shift when toggling evidence packets.
- [P3] Empty audit logs state: When audit logs array is empty on `/case/[id]`, empty card could offer a direct link or hint to trigger an agent run.
