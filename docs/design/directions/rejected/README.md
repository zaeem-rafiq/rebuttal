# Rejected Phase 2 Directions (Attempt 1)

These three directions were rejected because they were fundamentally one template with three surface palettes rather than genuinely divergent product architectures.

- **Direction A ("The Evidence Ledger"):** Failed because it preserved the default SaaS dashboard skeleton (top header, 4-column KPI row, 3-pill injection strip, and table list below) with mere dark-slate styling changes.
- **Direction B ("The Shield Terminal"):** Failed because it was functionally identical to Direction A in layout and hierarchy, merely recoloring the card borders and fonts with green terminal hues.
- **Direction C ("The Merchant Vanguard"):** Failed because it only partitioned the same table rows into two urgency boxes without changing how the user interacts, thinks, or solves the dispute problem.
